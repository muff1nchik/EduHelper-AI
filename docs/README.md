# Документация исходного кода

HTML-документация строится из docstrings рабочих модулей проекта.

```bash
python scripts/generate_docs.py
```

Готовые файлы создаются в `docs/generated/`.

Сгенерированные страницы отражают текущую рабочую логику проекта, включая
Telegram Rich Messages, проверку оформления LaTeX, безопасность LLM-запросов
и блокировку повторных тяжёлых запросов одного пользователя.
